# 🏢 ระบบจัดการหอพักภักดี (Pakdee Apartment Management System)

ระบบบริหารจัดการหอพักและอพาร์ตเมนต์แบบครบวงจร (Full-Stack Next.js 15 + TypeScript + Tailwind CSS) รองรับทั้งการจัดการผู้เช่ารายเดือน ผู้พักอาศัยรายวัน การออกใบแจ้งหนี้ ค่าน้ำค่าไฟ ผังสถานะห้องพัก และกระดานส่งต่องานแม่บ้าน

---

## 🚀 ฟีเจอร์หลักของระบบ (Key Features)

1. **ผังสถานะห้องพักแบบ Interactive (`/rooms`):**
   - ตัวกรองเลือกดูชั้นแบบ Single Dropdown (ทุกชั้น, ชั้น 1, 2, 3, 4)
   - แสดงสีสถานะชัดเจน (ว่าง=เขียว, รายเดือน=ส้ม, รายวัน=น้ำเงิน, ค้างชำระ=แดง, รอทำความสะอาด=เหลือง)
   - ป้องกันการลบห้องพักที่มีผู้เช่าอาศัยอยู่
2. **ระบบทะเบียนผู้เช่าและสัญญา (`/tenants`, `/tenants/new`):**
   - บันทึกเลขประจำตัวประชาชน 13 หลัก และเลขทะเบียนรถ
   - รองรับการเพิ่มรายการค่าใช้จ่ายเพิ่มเติม (Add Expense Button)
   - ผูกโยงเลขห้องพักอัตโนมัติ (Multi-source room resolution) ทั้งรายเดือนและรายวัน
3. **ระบบจองห้องพักรายวัน (`/daily`):**
   - บันทึกข้อมูลแขกรายวันอย่างเป็นหมวดหมู่ แยกส่วนหัวข้อและฟิลด์กรอกชัดเจน
   - ซิงค์ข้อมูลเข้าสู่ผังห้องพัก (ธีมสีน้ำเงิน) และตารางผู้เช่าอัตโนมัติ
4. **ระบบใบแจ้งหนี้และการวางบิล (`/invoices`):**
   - คำนวณมิเตอร์น้ำ-ไฟ และสรุปยอดค่าเช่าตามรอบบิลที่แม่นยำ
   - ดึงข้อมูลยอดค้างชำระไปแสดงที่ผังห้องพักและระบบแจ้งเตือนแบบเรียลไทม์
5. **กระดานแม่บ้านและงานทำความสะอาด (`/cleaning`):**
   - รองรับการส่งต่องานทำความสะอาดเมื่อ Check-out หรือส่งห้องรอทำความสะอาด
   - บันทึกสถานะถาวร ป้องกันข้อมูลเด้งกลับเมื่อ Refresh หรือ Login ใหม่
6. **ศูนย์การแจ้งเตือนและการตั้งค่า (`/settings`, Notification Bell):**
   - รวมศูนย์แจ้งเตือน 4 หมวด (ค้างชำระ, สัญญาใกล้หมดอายุ 30 วัน, งานแม่บ้าน, แจ้งซ่อม)
   - หน้าตั้งค่ารองรับ Dropdown ธนาคาร และช่องแนบไฟล์ลายเซ็น/ตราประทับหอพัก

---

## 🛠 ข้อมูลสำหรับทีม QA / นักพัฒนา (QA & Developer Guide)

- **Framework:** Next.js 15 (App Router) + React 19 + TypeScript
- **Styling:** Tailwind CSS + Lucide React Icons
- **Database / State:** Local Storage Service + JSON File Mock DB (ไม่ต้องติดตั้งฐานข้อมูลภายนอก สามารถรันได้ทันที)

### 📌 วิธีการติดตั้งและรันระบบ (How to Run)

1. **Clone Repository:**
   ```bash
   git clone <REPO_URL>
   cd <REPO_FOLDER>
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **เริ่มการทำงาน Development Server:**
   ```bash
   npm run dev
   ```

4. **เข้าใช้งานผ่านเบราว์เซอร์:**
   - URL: `http://localhost:3000`
   - รหัสผ่านเข้าใช้งาน (Demo / Admin):
     - เลือกบทบาท: **เจ้าของหอพัก (Owner)** หรือ **ผู้จัดการ (Manager)** ในหน้าเข้าสู่ระบบ หรือกดปุ่ม Quick Login เพื่อเริ่มทดสอบได้ทันที

## 🧪 ขอบเขตการทดสอบ (QA Test Scenarios)

1. **Scenario 1 - วงจรชีวิตผู้เช่ารายเดือน:**
   - การเปิดสัญญาจองห้องพักใหม่พร้อมกรอกเลขบัตร 13 หลัก และทะเบียนรถ
   - การตรวจสอบเลขห้องพักที่ปรากฏในหน้าทะเบียนผู้เช่า (`/tenants`)
   - การวางบิลและออกใบแจ้งหนี้ตามรอบบิล (`/invoices`)
2. **Scenario 2 - วงจรลูกค้ารายวันและการส่งต่องานแม่บ้าน:**
   - การบันทึกจองห้องรายวันในหน้า `/daily`
   - การตรวจสอบสีสถานะห้องรายวันบนผังห้องพัก (`/rooms`) ซึ่งต้องแสดงเป็น **สีน้ำเงิน**
   - การส่งต่องานทำความสะอาดและกดเสร็จสิ้นในหน้า `/cleaning` ตรวจสอบว่าไม่ออกแล้วเด้งกลับ
3. **Scenario 3 - ศูนย์การแจ้งเตือนและการตั้งค่า:**
   - การตรวจสอบกระดิ่งแจ้งเตือนมุมขวาบน และการคลิกลิงก์ไปยังหน้าที่เกี่ยวข้อง
   - การเลือกบัญชีธนาคารในหน้า `/settings` ผ่าน Select Dropdown
   - การแนบไฟล์รูปภาพลายเซ็นผู้มีอำนาจและตราประทับหอพัก
