### 🟡 บันทึกแนบท้ายสัญญา (Addendum) — เพิ่ม/เปลี่ยนเงื่อนไขหลังเซ็นสัญญา เช่น เพิ่มเช่าตู้เย็น
- **ผู้ใช้เลือกแบบ A:** สัญญาเดิมไม่ถูกแก้ ทำเอกสารแนบท้ายแยก เซ็นทั้งสองฝ่าย ดูสัญญาเดิมได้ตามปกติ
- **หน้าสัญญา:** สัญญาที่เซ็นแล้วมีปุ่ม "+ แนบท้าย" → `contract-addenda-modal.tsx` (ใหม่)
  - รายการบันทึกแนบท้ายของสัญญานั้น (ฉบับที่, วันที่มีผล, รายการ, สถานะ รอผู้เช่าเซ็น/มีผลแล้ว/ยกเลิก) + ดูเอกสารพร้อมลายเซ็นทั้งสองฝ่าย + พิมพ์ + ยกเลิกฉบับที่ยังรอเซ็น
  - ทำฉบับใหม่: วันที่มีผล (ค่าเริ่มต้นวันที่ 1 เดือนหน้า), ปุ่มเพิ่มด่วน ตู้เย็น/ทีวี/ที่จอดรถ/อินเทอร์เน็ต หรือรายการอื่น, ประเภท บาท/เดือน หรือ ครั้งเดียว, ข้อความเพิ่มเติม → "ส่งให้ผู้เช่าเซ็นทาง LINE"
  - ใช้ลายเซ็นผู้ให้เช่าของสัญญาหลัก (หรือจากตั้งค่าสาขา) — ถ้ายังไม่มีต้องเซ็นในสัญญาหลักก่อน
- **API** `api/contracts/addenda` (ใหม่) `list | create | cancel`: สร้างเอกสารฝั่งเซิร์ฟเวอร์จากข้อมูลที่ escape แล้ว (ข้อ 1 รายการ+วันที่มีผล, ข้อ 2 ข้อความเพิ่มเติม, ข้อสุดท้าย "ข้อความอื่นในสัญญาเดิมคงมีผลตามเดิม") + SHA-256, เลขฉบับเรียงต่อกันต่อสัญญา, ส่งการ์ด LINE "📝 บันทึกแนบท้ายสัญญา ฉบับที่ N" + สรุปสิ่งที่เปลี่ยน + ปุ่ม "อ่านและเซ็น" (หน้า `/sign` เดิม)
- `api/contracts/sign`: คำขอที่มี `addendum_id` → เซ็นแล้วอัปเดต `contract_addenda` (ไม่แตะลายเซ็น/สถานะของสัญญาหลัก) + ข้อความยืนยันใน LINE เป็น "ลงนามบันทึกแนบท้ายสัญญาเรียบร้อยแล้ว"
